URL Shortener with QR Code (MERN Stack)

October 2026 | Tech Stack: React.js, Vite, Node.js, Express.js, MongoDB, Mongoose, Tailwind CSS, DaisyUI, Render

  • Developed REST APIs in Express and MongoDB to create short links, redirect to the original URL, and track click count per link.
  • Generated unique IDs with nanoid and validated URL formats on the server before saving.
